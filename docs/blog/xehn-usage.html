XEHN VPN Client 是一个 Windows 上的 Cloudflare WARP 一键客户端：启动后点一下中间的圆钮，它会自动扫描最快的 WARP 端点、写好配置、拉起内核并接管系统代理，不用自己拼配置文件，也不用装任何运行库。

它做了什么

  • 自动注册 / 复用本机 WARP 设备账号，自动扫描最优端点
  • 支持 WireGuard、AmneziaWG（抗封锁）、MASQUE（H2 / H3）以及 WARP-in-WARP 链式
  • 系统代理模式开箱即用；需要整机流量可切到 TUN 全局模式
  • 可选 Psiphon、OpenVPN（VPN Gate）二次出口，并按实测速度自动换节点
  • 原生窗口，浅色 / 深色主题，中文 / English 一键切换

系统要求：Windows 10 / 11（64 位）。便携版免安装，解压即用，配置文件就放在程序旁边。

在文末下载压缩包，解压到任意可写目录（例如 D:\XEHN，不要放在 C:\Program Files 这类需要管理员权限的目录）。

三、点一下就连上

主界面长这样：左边是导航，中间是连接按钮，右边是当前的出口信息。

图 1 · 首页：中间的圆钮就是连接开关

操作顺序：

  1. 点中间的圆形「连接」按钮。
  2. 首次使用会自动注册本机 WARP 设备账号，然后扫描端点（约 1–2 分钟，之后有缓存会快很多）。
  3. 连上后，圆钮下方会显示出口 IP、国家/地区、延迟，下面两张卡片显示实时上传 / 下载速率。
  4. 再点一次即可断开，系统代理会自动还原。

圆钮下方那个下拉框是协议选择：默认 AWG（AmneziaWG，抗封锁能力更强）。连不上时可以换成 WG 或 MASQUE 再试；换协议时如果已经连着，它会自动热切换，不用手动断开。

右上角两个小药丸分别是主题（浅色 / 深色 / 跟随系统）和语言（中文 / English），随时点、立即生效。

四、按需调整设置（可选）

默认配置已经能直接用，多数人不需要动。想改的话点左侧「设置」，一页往下滚就是全部选项：

图 2 · 设置上半部分：接管方式与分流规则

接管方式

系统代理（默认，推荐）：只影响走系统代理的程序，不需要管理员权限。VPN / TUN：整机流量都进隧道，需要右键「以管理员身份运行」。

本地代理端口 / API 端口

默认 7890（HTTP + SOCKS 混合端口）和 9090。端口被占用时改这里，改完点「重新连接以应用」。

分流规则

预设里可选「自定义 / 绕过大陆 / 黑名单 / 全局 / 直连」。自定义模式下，直连域名走本地网络、代理域名走隧道，其余按预设处理。

图 3 · 设置下半部分：启动与行为、DNS 与出口

启动与行为

开机自启、启动后自动连接、连接前重新扫描、自动修复（断线后后台自愈）、连接超时。日常建议只打开「自动修复」。

DNS 与出口

可以指定自定义 DNS（如 223.5.5.5）、开启防 DNS 泄漏。出口除了 WARP 本身，还能挂 Psiphon 或 OpenVPN（VPN Gate 公共节点），后者会按实测速度挑节点、太慢自动换。

五、出问题看日志

左侧「日志」页有三个标签：运行日志（客户端和内核的实时输出）、连接记录（每次连接经过的步骤）、调试信息。连不上时，先看这里有没有红色/黄色提示。

图 4 · 日志页：右上角可一键清空或复制全文

遇到问题需要求助时，点「复制」把日志全文复制出来，比截图好排查。

六、常见问题

一直转圈，最后提示失败 换一个协议（AWG → WG → MASQUE）再试；或在协议下拉框旁重新扫描端点。日志里能看到具体卡在哪一步。
日志里出现黄色 WARN 多数是正常现象：连 OpenVPN 出口时，中继握手要几秒到二十秒，期间的探测会超时并被内核记为 WARN。后面出现「握手完成」「数据面验证通过」就是成功了。
TUN 模式起不来 TUN 需要管理员权限，右键 exe「以管理员身份运行」；或者切回系统代理模式。
杀毒软件报警 程序会修改系统代理、创建虚拟网卡，属于正常行为，加入信任即可。不放心的可以直接对照 GitHub 上的源码自行编译。
换电脑要不要重新配置 不用。压缩包里不含任何账号，每台新设备首次连接会自动注册一个独立的 WARP 设备账号。
关于页的控制码是什么 每台设备一个标识，用于识别被转卖或滥用的副本。正常使用不需要管它，也不会上传任何个人数据。
